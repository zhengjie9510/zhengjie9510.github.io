今天收到 OpenAI 的一封邮件，宣布未来几周将逐步整合 ChatGPT 的 **Chat（聊天）和 Work（工作）**，Codex 则继续保留独立入口。

不过，比界面整合更值得关注的是： **ChatGPT 和 Codex 将共用同一份额度。**

以前的 Chat 可不只是用来聊天。用高级模型分析文档、写代码、研究问题、制定方案，一样能完成不少复杂工作，而且不占用 Work 和 Codex
的工作额度。

**现在不一样了。** 新规则下，在 Chat 里使用高级模型处理这些任务，也将消耗共享额度。只有
**Instant（即时）模式仍然无限使用，不消耗共享额度。**

OpenAI 表示，预计大多数用户不会比现在更频繁地遇到额度耗尽的情况。但高级模型和复杂任务消耗更多额度，实际影响还得看最终的额度分配。

**Chat 和 Work 整合确实方便了，但以前能在 Chat 里完成、不占工作额度的事情，现在也要一起算账了。**

对于习惯用高级模型处理复杂任务的人来说，这次调整究竟是升级还是限制，恐怕还得等新规则上线后才能知道。
